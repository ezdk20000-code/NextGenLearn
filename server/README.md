# Сервер ИИ-наставника NGL

Claude по Anthropic API (по умолчанию `claude-opus-5-5`), личный профиль каждого ученика
и подключение других моделей — в том числе научных — без правки остального кода.

## Запуск

```bash
cd server
npm install
export ANTHROPIC_API_KEY=...   # ключ из console.anthropic.com
npm start                       # http://localhost:8787
```

Затем в прототипе: Профиль → ИИ-наставник → «Сервер NGL», адрес `http://localhost:8787`.
Без ключа сервер запускается и честно отвечает `503 not_configured`.

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/v1/ai/providers` | подключённые модели и научные инструменты |
| GET/PUT | `/api/v1/ai/profile` | личный профиль ученика: модель на каждую задачу, стиль, инструменты, память |
| POST | `/api/v1/ai/mentor` | разговор с наставником, поток SSE (`delta`, `tool`, `done`, `error`) |
| POST | `/api/v1/ai/grade` | проверка «объясни своими словами», наблюдение уходит в память |
| POST | `/api/v1/ai/cards` | флеш-карточки из конспекта |

Ученик определяется заголовком `x-ngl-user` (в рабочей версии — проверенный JWT).

## Другие модели

- **Научные модели** (Wolfram, SymPy, предикторы, своя модель по HTTP) — запись в `models.json`
  (пример: `models.example.json`). Модель становится инструментом наставника: Claude сам решает,
  когда её вызвать, и объясняет результат ученику.
- **Другие языковые модели** — класс, реализующий `ModelProvider` (`src/providers/types.ts`),
  регистрируется в `src/registry.ts`. Ученик выбирает его для любой задачи через `PUT /profile`.

## Надёжность

- Отказ по политике безопасности автоматически уходит на запасную модель (`fallbacks: "default"`).
- Ответы на проверки — структурированный вывод по JSON-схеме.
- Вычисления — через научные инструменты (`shared/sci-tools.ts`), а не «в уме».
