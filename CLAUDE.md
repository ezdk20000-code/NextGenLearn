# NextGenLearn — правила работы

## Дизайн: сначала Stitch
- Любая новая идея по дизайну (экран, раздел, лаборатория, обложка, крупная переделка интерфейса) сначала делается в Google Stitch, в проекте «AI Assistant Capabilities Guide» (id 7439399315135218094), с дизайн-системой Nocturne Mastery.
- Готовый экран показываем владельцу. В код сайта переносим только после его одобрения.
- Мелкие правки вёрстки (отступы, перенос строк, починка на телефоне) можно делать сразу в коде.
- Stitch MCP: `https://stitch.googleapis.com/mcp`, ключ передаётся в заголовке `X-Goog-Api-Key`. Ключ никогда не коммитится и не пишется в файлы репозитория.

## Контент курсов
- Книги владельца не попадают в репозиторий, их текст не копируется. Уроки пишутся своими словами со ссылкой на главу.
- Устаревшее в книгах подаётся блоком «было → стало».
- Каждый курс программы CS проверяется тестами на полноту (`tests/cs0.test.ts` — образец).

## Проверка перед коммитом
- `npx tsc -b`, `npx vitest run`, `npm run build`.
- Проверка в браузере на компьютере и на телефоне (без горизонтальной прокрутки).
