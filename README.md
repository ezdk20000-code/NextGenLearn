# NextGenLearn (NGL)

Система обучения, которая учит любого человека любой теме: граф понятий → интерактивные уроки → лаборатории → интервальное повторение (FSRS) → план и фокус.

Сейчас это **кликабельный прототип**. Два трека собраны полностью — «Сетевые протоколы с нуля» и «Гарвардский метод переговоров», ещё 8 есть в каталоге в виде программ.

Экраны: Сегодня, Каталог треков и страница программы, Древо знаний, Уроки, Лаборатории (TCP, подсети, инкапсуляция, переговоры), Deep Study, Флеш-карты и настройки FSRS, Конспекты, PlanFlow (учебные задачи: канбан, список, календарь дня, карточка задачи, фокус-помодоро), Аналитика, Портфолио, Профиль.

**PlanFlow** — учебный планировщик внутри NGL. Задачи — это уроки, лаборатории, повторение и свои учебные дела. Статусы: К выполнению → В работе → Самопроверка → Готово. Задача закрывается, только когда отмечены все критерии усвоения; пройденный урок или лаборатория сами двигают свою задачу.

## Запуск

```bash
npm install
npm run dev
npm test
```

## Структура

- `src/data/` — контент: `networks.ts` и `negotiation.ts` (полные треки), `catalog.ts` (программы), `types.ts` (формат трека, который будет генерировать ИИ).
- `src/lib/tasks.ts` — модель задач PlanFlow, статусы, приоритеты, генерация задач из трека.
- `src/lib/simulate.ts` — прогноз нагрузки повторений (Монте-Карло на FSRS).
- `src/components/blocks.tsx` — «примитивы» уроков: аналогия, вопрос, упорядочивание, «объясни сам», словарик.
- `src/pages/` — экраны: Сегодня, Новая тема, Древо, Урок, Лаборатории (TCP, подсети, инкапсуляция), Повторение, План и фокус.
- `src/lib/fsrs.ts` — алгоритм повторения FSRS-6 (общий для фронтенда и будущего бэкенда), тесты в `tests/`.
- `src/store.tsx` — прогресс пользователя (в прототипе хранится в localStorage).
- `db/schema.sql` — схема PostgreSQL 16 для бэкенда.
- `api/openapi.yaml` — контракт REST API.
- `docs/backend-brief.md` — бриф для ИИ, который будет писать бэкенд.

## ИИ-наставник

Наставник встроен в уроки, Deep Study, задачи PlanFlow и проверку «объясни своими словами». У каждого ученика своя интеграция: свой канал (его собственный аккаунт Claude на claude.ai, сервер NGL или офлайн), свои модели на задачи, свой стиль и память наставника. Научные модели подключаются как инструменты. Подробности — `server/README.md`, код — `src/ai/`, `shared/`.

Стек: Vite + React + TypeScript + Tailwind. Дизайн — тёмная тема Nocturne Mastery из макетов Stitch.

## Сайт

Сайт собирается и публикуется на GitHub Pages автоматически при каждом пуше в `main`
(`.github/workflows/deploy.yml`: зависимости → тесты → сборка → публикация).
Один раз в настройках репозитория: Settings → Pages → Source: **GitHub Actions**.

На отдельном сайте ИИ-наставник работает через сервер NGL (`server/`) — адрес задаётся
в Профиль → ИИ-наставник. Канал «Claude · твой аккаунт» доступен только внутри claude.ai.
